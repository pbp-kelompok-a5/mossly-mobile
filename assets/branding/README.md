# Mossly brand assets

The wood-and-moss M is the original Mossly mark from the group web repository:
https://github.com/pbp-kelompok-a5/mossly/blob/main/static/img/logo/logo-standalone.svg

The SVG is retained as the source. The transparent PNG is rendered at 4x for
Flutter Image.asset, so no SVG rendering package or network request is needed.

Typography follows the shared Mossly design tokens: Red Hat Display for
headings and Plus Jakarta Sans for body text. Font files and their OFL licenses
are bundled under assets/fonts/.
